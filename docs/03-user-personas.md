# User Personas

## Overview

Enterprise AI Workspace is designed for professionals and learners who regularly use AI, manage documents, and work on multiple projects. The platform focuses on improving productivity by reducing context switching and organizing work in one place.

---

# Persona 1 – Software Developer

## Profile
- Age: 20–35
- Works on coding projects
- Uses GitHub, VS Code, AI assistants

## Goals
- Generate code quickly
- Debug errors
- Organize project notes
- Store reusable prompts

## Pain Points
- Switching between ChatGPT, GitHub, and documentation
- Losing previous AI conversations
- Managing multiple coding projects

## How Enterprise AI Workspace Helps
- Dedicated coding workspace
- Multiple AI models in one place
- Project-specific chat history
- Document management

---

# Persona 2 – College Student

## Profile
- Studies engineering or other technical courses
- Uses AI for learning and assignments

## Goals
- Study faster
- Prepare notes
- Understand concepts
- Organize subjects

## Pain Points
- Notes scattered across folders
- AI chats get lost
- Difficult to manage PDFs and assignments

## How Enterprise AI Workspace Helps
- Subject-wise workspaces
- PDF chat
- AI summaries
- Centralized study material
